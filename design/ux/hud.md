## HUD Philosophy

**결정 정보는 상시, 조작 안내는 상황형** (2026-11-17 확정).

배송 순서·남은 시간·내구도·방향은 주행 중 계속 판단에 쓰므로 항상 보인다. Space/R 키 안내, 과적 아이콘, 토스트처럼 지금 할 수 있는 조작이나 방금 생긴 일은 필요할 때만 나타나고 사라진다. 새 요소는 이 기준으로 상시인지 상황형인지 먼저 정한다.

화면(HUD 아님): 물류센터 창(8.1), 정산 화면(12.2). 각각 주행 HUD 위에 열리는 별도 화면이며 이 문서는 그 화면이 열렸을 때 HUD가 어떻게 바뀌는지만 다룬다.

### Categorization

- Must Show 6개(1·2·3·4·5·7): 배송 판단과 시간 관리에 계속 쓴다.
- Contextual 8개(6·8~14): 조건이 맞을 때만 나타난다.
- On Demand: 없음. 적재 그룹 접기·펼치기(숫자 키, Story 014)는 표시 밀도 조절이며 정보 자체를 숨기지 않는다.
- Hidden: 상호작용 구역은 월드의 빛기둥으로만 알린다.

## Layout Zones

기준 해상도 1920×1080, `HudPanelSettings` Scale With Screen Size, Match 0.5. 문서의 px 값은 모두 이 기준이다.

```
┌──────────────────────────────────────────────────────────────┐
│ [좌상단]              [상단 중앙]                 [우상단]   │
│ 09:30                 ┌ 토스트 (최대 3) ┐        ┌ 물류센터 ┐ │
│ DAY 1                 └─────────────────┘        ├ 배송 현황 ┤ │
│ 1,200₩                                           └ 폐기     ┘ │
│                                                              │
│                  [R]   (플레이어)   [Space ▣]                │
│                          −12                                 │
│                                                              │
│                     [과적 −33%]                              │
│                   [  속도계·게이지  ]                        │
│                       [하단 중앙]                            │
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 안전 여백 |
|---|---|---|
| 좌상단 | 시각, 일차, 오늘 수익 | 24px |
| 상단 중앙 | 토스트 | 위 24px |
| 우상단 | 물류센터·배송 현황·폐기 패널 세로 열 | 24px |
| 하단 중앙 | 속도계·게이지, 그 위 적재 상태 아이콘 줄 | 아래 24px |
| 플레이어 좌우 | 왼쪽 R 패널, 오른쪽 Space 패널(플레이어 화면 위치에서 ±70px) | 플레이어를 따라감 |
| 차량 위 | `−N` 팝업 | 플레이어를 따라감 |

안전 여백은 PC 모니터 기준이다. 콘솔·TV용 5% 안전 영역은 대상 플랫폼이 아니므로 두지 않는다.

## HUD Element Specifications

| # | 요소 | 분류 | 형태 | 갱신 | 표시 조건 | 연출 |
|---|---|---|---|---|---|---|
| 1 | 시각 | Must Show | 큰 숫자 `HH:mm` | 게임 분 단위 | 운영 중 | 없음 |
| 2 | 일차 | Must Show | 작은 글자 `DAY N` | 하루 시작 | 운영 중 | 없음 |
| 3 | 오늘 수익 | Must Show | 정수 `₩`, 음수는 경고색 + `−` 부호 | 배송 완료 이벤트 | 운영 중 | 없음 |
| 4 | 물류센터 패널 | Must Show | 나침반 배지(회전 화살표) + `물류센터` + 거리 `24m` | 매 프레임 | 항상(적재 물류 0개여도) | 화살표 회전 |
| 5 | 배송 현황 패널 | Must Show | 그룹 헤더(배지·번호 키·거리) + 물류 행 | 행: 적재 변화 이벤트 / 바·거리: 매 프레임 | 배송지 그룹 1개 이상 | 접기·펼치기(숫자 키) |
| 6 | 폐기 패널 | Contextual | 회색 테두리, 처분 장소 그룹 | 폐기 전환 이벤트 | 폐기 물류 1개 이상 | 없음 |
| 7 | 속도계·게이지 | Must Show | 숫자 `km/h` + 고속 게이지 | 매 프레임 | 운영 중 | 고속 모드 시 강조색 |
| 8 | 적재 상태 아이콘 줄 | Contextual | 작은 과적 아이콘 + `−33%` | 적재 변화 | 무게 한도 초과 | 없음 |
| 9 | 토스트 | Contextual | 상단 카드 스택 | 이벤트 | 아래 Feedback 절 | 0.3초 내려오며 페이드 인/올라가며 페이드 아웃 |
| 10 | Space 패널 | Contextual | 키캡 `Space` + 종류 아이콘(상차·하차·폐기·방해물) | 대상 변화 이벤트, 아이콘은 매 프레임 확인 | 대상 있음, 운영 중, 조작 잠금 아님 | 홀드 진행도만큼 아래→위 채움(파랑) |
| 11 | R 패널 | Contextual | 키캡 `R` | 갇힘·홀드 이벤트 | 갇힘(1.5초 지속) 또는 R 홀드 중, 운영 중, 복구 잠금 아님 | 홀드 진행도만큼 아래→위 채움(주황) |
| 12 | `−N` 팝업 | Contextual | 큰 숫자 | 충돌 이벤트 | 내구도 감소 발생 | 위로 떠오르며 사라짐 |
| 13·14 | 월드 물류 아이콘 | Contextual | 월드 공간 아이콘 | 할당·적재 변화 | 해당 장소 근처 | 없음 |

물류 행(5·6)의 세부: 유형 아이콘(색) + 유형 태그(`#특급`/`#신선`) + 가격 + 특징 태그 + 내구도 + 제한 시간 바. 유형 태그는 색 구분의 대체 수단이다(Accessibility 절).

## Visual Budget

- 동시 표시 요소 최대: 화면 공간 HUD 11개(1~11). 월드 공간 아이콘(12~14)은 제외한다.
- 화면 점유 목표: 주행 중 HUD 전체가 화면 면적의 25% 이하. 우상단 열은 화면 높이의 70%를 넘지 않으며, 넘으면 Story 014의 접기·스크롤 규칙으로 줄인다.
- 측정되지 않은 목표치다. 인수 조건에서 측정한다.
- 예산을 넘으면 줄이는 순서: (1) 배송 현황 그룹 접기(플레이어 조작) → (2) 우상단 열 스크롤 → (3) 토스트 동시 표시 3개 → 2개. MUST KEEP 요소는 줄이지 않는다.

## Accessibility

등급: **Basic** (`design/accessibility-requirements.md`, 2026-11-17 확정).

- 색만으로 전달 금지:
  - 배송 유형: 아이콘 색 + 유형 태그 `#특급`/`#신선` (2026-11-17 결정)
  - 수익 음수: 경고색 + `−` 부호
  - 폐기: 회색 + `#폐기` 태그, 시간 초과: 바 비움 + `#지연` 태그
  - 물류센터: 파란 화살표 + `물류센터` 글자
  - Space/R 채움색(파랑/주황): 위치(좌/우)와 키 글자로 구분됨
  - **고속 모드 게이지 강조색은 색만으로 전달한다. 미해결(Open Questions).**
- 최소 글자 크기: 게임 정보를 담은 글자는 16px 이상(1080p 기준). 현재 13·14px 글자가 `DurabilityHud.uss`에 있다. 미해결(Open Questions).
- 상호작용 가능한 HUD 요소는 없다(포커스 순서 N/A). 키 입력은 Space·R·숫자 키뿐이다.
- 움직임: 토스트 0.3초 슬라이드, `−N` 팝업, 나침반 회전. 깜박임은 없다. 동작 줄이기 옵션은 Basic 범위 밖이다.

## Acceptance Criteria

- [ ] 1920×1080에서 좌상단·우상단·하단 중앙 요소가 화면 가장자리에서 24px 이상 떨어져 있다
- [ ] 1280×720과 2560×1440에서 HUD 요소끼리 겹치지 않고 글자가 잘리지 않는다
- [ ] 적재 물류가 0개일 때 우상단에 `물류센터` 패널만 보인다
- [ ] 주행 중 화면 공간 HUD가 11개를 넘지 않고, 배송지 그룹 4개를 모두 펼쳐도 우상단 열이 화면 높이의 70%를 넘지 않는다
