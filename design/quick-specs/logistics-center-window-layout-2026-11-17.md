# Quick Design Spec: 물류센터 상차 창 개편 (1열 카드 레이아웃)

**Type**: Addition
**System**: 물류센터 상차 UI (`LogisticsCenterUI`)
**GDD Reference**: `design/gdd/game-concept.md` 8.1 물류센터 UI, 8.2 상차 선택 방식 / `design/gdd/delivery-cargo-vehicle-rules.md` 6.4
**Date**: 2026-11-17

## Change Summary

물류센터 상차 창을 고정폭 텍스트 목록(`#12 EXP F-- C1 W2 14:30`)에서 배송지별 카드를 1열로 쌓는 형태로 바꾼다. 행 구성은 적재 물류 HUD(`DurabilityHud`)와 같다(유형 아이콘, 예상 보상, 해시태그).

## Motivation

지금 행은 약어와 고정폭 코드로 되어 있어 처음 보는 플레이어가 읽기 어렵고, 적재 HUD와 표기가 달라 같은 물류가 화면마다 다르게 보인다. 상차를 고르는 순간에 필요한 정보(얼마를 받는지, 무엇을 조심해야 하는지, 언제까지인지)가 바로 보이게 한다. 초안 이미지는 2열이지만 현행대로 1열로 둔다.

## Design Delta

- 현재: 그룹 머리글 한 줄(`배송지A  200m  x3  loaded 1`) 아래에 물류마다 고정폭 텍스트 행. 맨 위에 `CARGO 12/16   WEIGHT 12/16` 한 줄.
- 변경: 아래 레이아웃. 정렬, 선택, 홀드 상차, 비활성 규칙(8.1·8.2·6.4)은 바꾸지 않는다.

## New Rules / Values

**1. 창 머리**
- 제목 `물류센터`, 설명 `배송할 물류를 확인하고 차량에 상차할 수 있습니다.`. 오른쪽 위 닫기 `✕`(기존 닫기와 같은 동작).
- 구분선 아래 왼쪽: `총 물류 개수: N`. N은 물류센터에 남은 미적재 물류 수(폐기 물류 제외).
- 오른쪽 배지 두 개: `적재 한도: 사용/한도`, `무게 한도: 사용/한도`. 무게가 한도 W를 넘으면 무게 배지를 경고색으로 표시한다(6.4).

**2. 목록: 1열, 세로 스크롤**
- 배송지 카드를 위에서 아래로 한 줄에 하나씩 쌓는다. 카드 폭은 목록 폭과 같다.
- 정렬은 기존대로: 카드는 거리순, 카드 안 물류는 처리 순서(7.4).
- 목록이 창 높이를 넘으면 마우스 휠로 스크롤하고 오른쪽에 스크롤바를 표시한다.
- 상차로 행이 사라지거나 다시 그려져도 스크롤 위치를 유지한다.

**3. 배송지 카드**
- 헤더: `📍 배송지명`, 흐린 글씨의 거리 `200m`, 오른쪽 `남은 N · 적재 N`. 미적재 수와 적재 수는 따로 표시한다(8.1).
- 헤더를 누르고 있으면 그룹 상차(8.2). 첫 물류를 실을 수 없으면 헤더를 비활성으로 표시한다(결정 D5).
- 물류가 모두 실린 카드도 헤더만 남겨 `남은 0`으로 표시한다(8.2).

**4. 물류 행 (적재 HUD 행과 같은 구성)**
- 왼쪽 아이콘: 배송 유형 색. Normal 파랑, Express 빨강. Fresh는 Story 008에서 초록 아이콘을 추가한다.
- 첫 줄: 예상 보상 전액 `1,100₩`(기본 + 거리 + 특징 + 시간 보너스, HUD와 같은 식).
- 둘째 줄: 해시태그 칩 `#취급주의` `#고중량` `#대형`. 특징이 없으면 칩을 두지 않는다(HUD와 같다). 물류별 적재 용량·무게 숫자는 표시하지 않는다(HUD와 같다).
- Express 행만 아래에 제한 시간 바를 두고, 바 오른쪽에 만료 시각 `HH:mm`을 표시한다. Normal 행에는 바와 시각이 없다.
- 행을 누르고 있으면 개별 상차(8.2).
- 마우스를 올리면 그 행의 배경을 밝히고 테두리를 밝은 회색으로 강조한다(살짝 커짐). 카드 헤더에 올리면 그룹 상차로 실릴 행(실을 수 있는 행)을 함께 강조한다.
- 상차 중에는 지금 실리는 물류 행(그룹 상차면 처리 순서 첫 행)의 테두리를 어둡게 두고, 물류 하나의 상차 진행도(8.2)만큼 위 가운데에서 시계 방향으로 테두리를 따라 초록 선이 차오른다. 다음 물류로 넘어가면 다음 행에서 다시 시작한다. 떼거나 벗어나면 선이 사라진다.

**5. 상태 표시**
- 실을 수 없는 행(적재 한도 초과, `W_max` 초과)은 행 전체를 흐리게 두고 누를 수 없게 하며, 사유 칩 `#적재 초과` 또는 `#무게 초과`를 붙인다(지금의 `WEIGHT LIMIT` 문구를 대신한다).
- 상차하면 W를 넘지만 `W_max` 이내인 행은 금액을 경고색으로 표시하고 누를 수 있게 둔다(6.4).

**6. 처분 장소 카드**
- 실린 폐기 물류가 있으면 목록 맨 끝에 `처분 장소 Nm · 폐기 N` 카드를 경고색으로 둔다. 누를 수 없다(기존과 같다).

**7. 구현 메모**
- 적재 HUD처럼 UI Toolkit으로 만들고 같은 폰트·색 체계를 쓴다. 홀드 상차는 UI Toolkit 포인터 이벤트(누름 → 시작, 뗌·벗어남 → 중단)로 옮긴다.
- 모든 문구는 한글. Story 020이 이 창에서 맡던 `CARGO`/`WEIGHT`/`WEIGHT LIMIT` 문구 변경은 이 개편에 흡수된다.

## Acceptance Criteria

- [ ] 배송지 카드가 1열·거리순으로 쌓이고, 넘치면 마우스 휠로 스크롤된다
- [ ] 머리에 `총 물류 개수`, `적재 한도`, `무게 한도` 배지가 실제 값으로 표시되고, 무게가 W를 넘으면 무게 배지가 경고색이 된다
- [ ] 물류 행의 금액·아이콘색·해시태그가 같은 물류의 적재 HUD 행과 같다
- [ ] Express 행에만 제한 시간 바와 `HH:mm`이 있고 바가 실시간으로 줄어든다
- [ ] 헤더 홀드는 그룹 상차, 행 홀드는 개별 상차를 하고, 진행 중인 항목에 초록 테두리가 보인다
- [ ] 실을 수 없는 행은 흐린 표시와 `#적재 초과`/`#무게 초과` 칩으로 표시되고 눌리지 않는다
- [ ] 상차로 행이 사라져도 스크롤 위치가 튀지 않는다
- [ ] 회귀 없음: 정렬, 그룹 상차의 W 정지(D5), 닫기 시 상차 취소, 영업 종료 시 자동 닫힘이 기존대로 동작한다
- [ ] 새 화면 스크린샷을 `production/qa/evidence/`에 보관한다
