# Quick Design Spec: HUD 화면 배치

**Type**: Addition
**System**: HUD 전체 배치 (게임 시간, 오늘 수익, 방향 안내, 적재 물류 패널)
**GDD Reference**: `design/gdd/game-concept.md` 3.3·13장
**Date**: 2026-11-17

## Change Summary

주행 화면의 HUD를 영역별로 고정한다. 좌상단에 일차·시각과 오늘 수익을 두고, 상단 나침반 패널을 없애 방향 화살표를 우상단 적재 물류 패널의 행으로 옮긴다.

## Motivation

시각·재화 HUD의 자리가 없었고, 상단 중앙은 나침반 패널이 차지하고 있었다. 방향 안내를 적재 물류 패널에 붙이면 "어느 배송지가 어느 쪽인가"를 물류 목록과 한곳에서 읽는다.

## Design Delta

- 기존: 시각 `HH:mm`(위치 미정), 재화 HUD 없음, 상단 중앙 나침반 패널에 화살표를 가로로 배치.
- 변경: 좌상단 시각 `HH:mm`(크게) · 그 아래 `DAY N`(작게) + 오늘 수익, 상단 나침반 패널 제거, 적재 물류 패널 행별 화살표.

## New Rules / Values

### 화면 영역

| 영역 | 내용 |
|---|---|
| 좌상단 | 1행 시각 `HH:mm`(크게, 2026-11-17 확정), 2행 `DAY N`(작게), 3행 오늘 수익 |
| 상단 중앙 | 토스트 알림 (아래 "토스트 알림" 절) |
| 우상단 | 세로 열에 세 패널: 물류센터 패널(항상), 배송 현황 패널(배송지 그룹, 없으면 숨김), 폐기 패널(처분 장소 그룹, 없으면 숨김). 2026-11-17 개정 |
| 하단 중앙 | 속도계와 고속 모드 게이지, 그 위 적재 상태 아이콘 줄 (아래 "하단 중앙" 절) |
| 플레이어 오른쪽 (스크린 공간, 플레이어 화면 위치 기준) | 상호작용 키 안내 아이콘(Space, R)과 진행 바(상·하차·복구 공용) |

### 하단 중앙 (2026-11-17 확정, 아래에서 위로)

1. 속도계 + 고속 모드 게이지 (Story 013). 고속 모드일 때 게이지를 강조색으로 표시한다. 주행 모드 글자 HUD는 두지 않는다(임시).
2. 적재 상태 아이콘 줄: 속도계 바로 위, 중앙 정렬, 작은 아이콘. 지금은 과적 아이콘과 감소율(`−33%`) 하나이며, 무게 한도 이내면 숨긴다.

차단 사유 문구는 여기에 두지 않고 토스트 알림으로 보낸다(아래).

### 토스트 알림 (2026-11-17 확정)

- 위치: 상단 중앙. 스마트폰 팝업 알림처럼 위에서 아래로 쌓인다(최신이 위).
- 연출: 등장 0.3초(위에서 내려오며 페이드 인) → 유지 → 퇴장 0.3초(위로 올라가며 페이드 아웃).
- 유지 시간: 기본 2초, 차단 사유 1.5초.
- 동시 표시 최대 3개. 넘치면 가장 오래된 알림을 즉시 퇴장시킨다.
- 같은 문구가 표시 중에 다시 오면 새로 쌓지 않고 그 알림의 유지 시간만 다시 시작한다.
- 알림 종류:

| 종류 | 트리거 | 문구 예 |
|---|---|---|
| 동적 물류 생성 | 동적 물류 1개 생성 (정적 물류 제외) | `새 물류 — 배송지 A · Express` |
| 차단 사유 | 상호작용 차단 | `적재 공간 부족` |
| 폐기 | 물류가 폐기로 전환 | `물류가 폐기되었습니다 — 처분 장소로 이동` |

- 하루 종료(조작 잠금) 뒤에는 새 알림을 띄우지 않는다. 정산 화면이 열리면 남은 알림을 지운다.
- 시간·개수 값은 USS/`[SerializeField]`로 둔다(`TODO(tuning)`).

### 문구 언어 (2026-11-17 확정)

화면 문구는 한국어로 통일한다. 숫자·단위(`km/h`, `₩`)와 키 이름은 예외다.

### 상호작용 키 안내 (2026-11-17 확정)

- 지금 할 수 있는 상호작용을 키 아이콘으로 표시한다. 상·하차 등 대상별 아이콘(Space)은 기존처럼 하나만 켜진다.
- R키 아이콘(임시)은 그 선택과 별개로, 하루 운영 중 조작 가능하면 항상 표시하고 하루 종료 후 숨긴다.
- R을 누르는 동안 복구 진행도를 상·하차와 같은 진행 바에 표시하고, 떼면 바가 사라진다.
- 복구 후 조작 잠금 중에는 R키 아이콘을 흐리게(반투명) 표시한다.

### 일차

- 1부터 시작한다. 하루가 시작될 때 정해지고 그날 동안 바뀌지 않는다.
- 여러 날 진행이 없는 현재 마일스톤에서는 항상 `DAY 1`이다.

### 오늘 수익

- 값 = 그날 배송 완료된 물류의 보상 합계(기본 배송료 + 거리 추가 배송료 + 시간 추가 보상 + 특징 보상) − 시간 초과 손실 합계.
- 배송 완료 시점에 갱신한다. 배송 실패 페널티(폐기·미배송)는 넣지 않는다. 정산 화면에서만 반영된다.
- 하루 시작 시 0. 음수면 경고색. 정수로 표시한다.
- 정산 화면이 열리면 시각·수익 HUD를 숨긴다(3.3 "정산 화면에서는 시계를 표시하지 않는다").

### 방향 화살표

- `물류센터` 패널: 우상단 열 맨 위에 항상 표시한다. 화살표·패널 테두리는 파란색.
- 폐기 패널: 배송 현황 패널 아래 별도 패널. 폐기 그룹의 숫자 키 번호는 항상 마지막이다. 테두리는 어두운 회색.
- 배송지 그룹·처분 장소 그룹: 헤더의 가장 왼쪽에 원형 나침반 배지(테두리 고정, 안의 화살표만 회전)를 둔다. `물류센터` 행도 같은 배지를 쓴다(2026-11-17 개정).
- 화살표는 차량 전방을 위로 하여 목적지 방향으로 회전한다(차량 기준 상대 방향).
- 그룹 순서는 적재 물류 패널의 기존 순서를 따른다. 그룹 번호 키(Story 014)는 `물류센터` 행에 붙이지 않는다.
- 행 오른쪽 끝 열에 목적지까지의 수평 거리를 정수 미터(`24m`)로 오른쪽 정렬해 표시하고 매 프레임 갱신한다(2026-11-17 추가).
- 화살표 그림은 Bootstrap Icons `cursor-fill` SVG(임시 GUI, 2026-11-17).
- 그룹 헤더에 접힘 표시(`▶`/`▼`)를 두지 않는다(2026-11-17). 접기/펼치기는 숫자 키(Story 014)로만 한다.

### 물류 행 (적재 물류 패널)

- 구성: 유형 아이콘, 가격(`600₩`), 특징 태그(`#취급주의` 등), 내구도(`82/100`). Normal 행은 이것뿐이다.
- 제한 시간이 있는 물류(Express, Fresh)는 행 아래쪽에 가로 바를 둔다. 길이 = 남은 제한 시간 ÷ 전체 제한 시간. 주행 중 매 프레임 줄어든다.
- Express 시간 초과: 바를 비우고 `#지연` 태그를 붙인다. 배송 실패가 아니므로 행은 남는다.
- Fresh 신선도 0: 폐기로 전환되어 처분 장소 그룹으로 옮겨지고 바를 숨긴다(`#폐기` 태그).
- 바 색(임시, 2026-11-17): 유형 아이콘 색과 같게 Express 빨강, Fresh 초록. 아이콘 그림은 Bootstrap Icons `box-seam-fill`에 유형 색(Normal 상자 노랑, Express 빨강, Fresh 초록, 폐기 어두운 회색). `물류센터` 나침반은 파랑.
- 특징·상태 태그(`#취급주의`, `#고중량`, `#대형`, `#폐기`, `#지연`)는 글자 칩을 유지한다. Bootstrap Icons로 모두 대응되지 않아(취급주의·고중량 없음) 전용 이미지가 생기면 다시 정한다(2026-11-17).

### Tuning Knobs

| 값 | 기본 | 위치 |
|---|---|---|
| 좌상단 여백 | 24px | USS |
| 수익 음수 경고색 | 정산 화면 손실색과 같음 | USS |
| 물류센터 화살표 색 | 기존 나침반 파란색 (0.549, 0.778, 0.961) | USS |

## Acceptance Criteria

- 좌상단에 시각 `09:30`(위, 크게)과 `DAY 1`(아래, 작게), 오늘 수익이 보이고, 정산 화면에서 숨겨진다
- 배송 완료 시 오늘 수익이 그 물류의 보상 − 시간 초과 손실만큼 바뀐다
- 상단 중앙에 나침반 패널이 없고, 적재 패널의 각 행 화살표가 목적지를 가리킨다
- 적재 물류가 없어도 `물류센터` 패널과 화살표가 보인다
- 각 행에 나침반 배지와 목적지까지의 거리(m)가 보인다
