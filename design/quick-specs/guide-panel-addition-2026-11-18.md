# Quick Design Spec: 게임 설명 패널과 Esc 처리

**Type**: Addition
**System**: 시작 화면(StartMenuUI), 종료 흐름(GameManager)
**GDD Reference**: `design/quick-specs/start-screen-2026-11-18.md`(Core Rules 5, 후속 스토리), `design/game-brief.md`, `design/gdd/delivery-cargo-vehicle-rules.md`, `design/gdd/collision-durability-rules.md`
**Date**: 2026-11-18
**Estimated Implementation**: 6~8시간 (게임 설명 패널 3~4시간, Esc 처리와 퇴근 확인창 3~4시간)

## Change Summary

1. 시작 메뉴의 "조작법" 버튼을 **"게임 설명"** 으로 바꾸고 활성화한다. 누르면 로고와 버튼이 사라지고, 오른쪽 영역에 스크롤되는 설명 패널이 뜬다. X 버튼으로 닫으면 시작 메뉴로 돌아온다.
2. **Esc** 를 단계별로 처리한다. 열려 있는 패널이 있으면 그것을 닫고, 없으면 게임을 정지한 뒤 "퇴근하시겠습니까?" 확인창(예/아니오)을 띄운다.

## Motivation

- 새 플레이어가 조작법과 규칙을 읽고 시작하게 한다. 지금은 조작법 버튼이 비활성이라 설명할 곳이 없다.
- 지금 Esc는 어디서든 즉시 종료라서, 설명을 읽다가나 물류센터 창을 보다가 누르면 게임이 꺼진다.

## Design Delta

선행 스펙 `start-screen-2026-11-18.md`는 "조작법 버튼은 비활성, `ControlsRequested` 이벤트만 선언"(Core Rules 5)이었고, Esc는 "지금처럼 종료로 동작한다"(Core Rules 6)였다. 이 스펙이 두 부분을 아래로 바꾼다.

### A. 게임 설명 패널

1. **버튼**: 문구는 `게임 설명`이고 활성화한다. 사선 배치는 그대로다. `ControlsRequested` 이벤트는 구독자가 없어 삭제하고 패널은 `StartMenuUI` 안에서 처리한다.
2. **열기**: 게임 설명을 누르면 `menuArea`(로고와 버튼 3개)를 `display:none`으로 숨기고 `guidePanel`을 보인다. `MenuCam`, 하루 정지 상태, HUD 숨김은 그대로다. 출근 버튼이 숨겨지므로 패널이 열린 동안 하루는 시작되지 않는다.
3. **배치**: 패널은 메뉴가 쓰던 오른쪽 영역과 같은 폭(`MenuWidthPercent`)에 놓고 바깥 여백은 48px다. 패널 왼쪽 끝은 화면 55% 위치보다 오른쪽이라 왼쪽의 차량을 가리지 않는다. 높이는 화면에서 위아래 여백을 뺀 만큼이다.
4. **구성**: 물류센터 창과 같은 모습이다(2026-11-18 사용자 요청, `LogisticsCenterWindow.uss` 클래스 재사용). 제목 `게임 설명`과 부제 `조작법과 하루 운영 규칙을 확인할 수 있습니다.`, 오른쪽 위 X 버튼(Bootstrap Icons `x-lg` SVG), 구분선, 세로 `ScrollView`(얇은 어두운 스크롤바)가 있다. 섹션은 카드 하나씩이고, 조작법·배송 유형·물류 특징은 행마다 키·유형 배지와 설명을 둔다(신속 빨강, 신선 초록은 적재 HUD와 같은 색).
5. **닫기**: X를 누르면 `guidePanel`을 숨기고 `menuArea`를 다시 보인다. 열 때마다 스크롤을 맨 위로 되돌린다. 닫으면 포커스가 `게임 설명` 버튼으로 돌아온다.
6. **키보드**: 열면 포커스가 X 버튼에 가고 ↑/↓, PageUp/PageDown으로 스크롤한다. X는 Enter로 닫는다.
7. **내용**: 정적 한국어 텍스트이며 UXML에 직접 쓴다(Story 020 방식). 속도·확률·금액 같은 밸런싱 수치는 넣지 않는다. 규칙이 바뀌면 이 문구도 함께 고친다.

### B. Esc 처리

Esc를 한 번 누르면 아래 순서에서 **처음 해당하는 것 하나만** 처리한다. 같은 키 입력으로 두 가지가 동시에 일어나지 않는다.

| 순서 | 상태 | Esc 동작 |
|---|---|---|
| 1 | 퇴근 확인창이 열려 있음 | 확인창을 닫고 게임을 재개한다(아니오와 같음) |
| 2 | 게임 설명 패널이 열려 있음 | 패널을 닫고 시작 메뉴로 돌아간다(X와 같음) |
| 3 | 물류센터 창이 열려 있음 | 창을 닫는다(닫기 버튼과 같음, 닫기 효과음 포함) |
| 4 | 그 외(시작 메뉴, 하루 운영 중, 정산 화면) | 게임을 정지하고 퇴근 확인창을 띄운다 |

**퇴근 확인창**
- 문구: `게임을 정지하고 퇴근하시겠습니까?`, 버튼은 `예` / `아니오`.
- 화면 전체를 어둡게 덮는 모달이고, 다른 모든 UI 위에 보인다.
- `예`: 기존 `GameManager.Quit()`와 같은 종료(Editor는 플레이 중지, 빌드는 `Application.Quit()`).
- `아니오`: 확인창을 닫고 정지를 풀어 직전 상태로 돌아간다.
- 처음 포커스는 `아니오`다(실수로 종료되지 않게). ←/→로 이동하고 Enter로 선택하며 마우스 클릭도 된다.
- **정지**: 확인창이 열려 있는 동안 하루 시계, 물류 생성, Express 제한 시간과 Fresh 신선도, 차량 물리, 플레이어 입력(이동·Space·R·Ctrl·Shift)이 모두 멈춘다. 닫으면 정지 전 상태 그대로 이어진다.
- 시작 메뉴 화면에서 Esc를 눌러도 같은 확인창이 뜬다(정지할 게임은 없다).
- 시작 메뉴의 **퇴근 버튼**은 지금처럼 확인창 없이 즉시 종료한다(직접 누른 것이므로).
- 이 정지는 확인창이 떠 있는 동안만이며, 일시정지 메뉴가 아니다(브리프 Out of scope 유지).
- 정지 구현 방식은 구현 때 정한다. 단 `GameTimeSystem`이 `Time.timeScale`을 건드리지 않는 설계이므로, `timeScale`을 쓸지 공통 정지 플래그를 둘지는 거기서 확인한다.

### 패널 본문 (확정 초안)

**1. 게임 목표**
물류센터에서 물류를 싣고 배송지에 내려 하루(09:00~18:00)의 수익을 만드세요. 하루가 끝나면 정산과 함께 별 0~3개로 평가받습니다.

**2. 조작법**
- ↑ ↓ ← → : 차량 이동
- Ctrl : 일반 / 고속 주행 모드 전환 (고속은 게이지를 소모하고, 전환에는 쿨다운이 있습니다)
- Shift + ← → : 드리프트
- Space : 물류센터·배송지·처분 장소에서 UI 열기. 꾹 누르면 상차·하차·처분
- R (꾹 누르기) : 갇혔을 때 차량 복구
- 적재 물류 패널 : 숫자 1~9 그룹 펼침/접기, 0 전체 펼침, ` 전체 접기, 마우스 휠·PageUp/PageDown 스크롤
- Esc : 열린 창 닫기 / 퇴근 확인

**3. 하루의 흐름**
출근하면 하루가 시작되고 기본 물류가 생깁니다. 16:00까지 새 물류가 계속 추가됩니다. 18:00이 되거나 모든 배송을 마치면 하루가 끝나고 정산합니다. UI를 열어 두어도 시간은 멈추지 않습니다.

**4. 배송 유형**
- 일반: 제한 시간이 없습니다.
- 신속(Express): 제한 시간 안에 배송하면 추가 보상을 받고, 넘기면 보상이 줄고 손실이 생깁니다.
- 신선(Fresh): 싣는 순간부터 신선도가 줄어듭니다. 0이 되면 폐기되어 배송에 실패합니다.

**5. 물류 특징**
취급주의(충돌에 약함), 고중량(무게 한도를 더 씀), 대형(적재 한도를 더 씀). 특징이 많을수록 보상이 커집니다.

**6. 적재 한도**
적재 한도는 넘길 수 없습니다. 무게 한도는 일정 배율까지 넘겨 실을 수 있지만 그만큼 차량이 느려집니다.

**7. 충돌과 폐기**
충돌하면 실린 물류의 내구도가 줄고, 세게 부딪힐수록 많이 줄어듭니다. 0이 되면 폐기 물류가 되어 배송할 수 없고 처분 장소에서 버려야 합니다. 충돌 자체로 속도나 돈이 깎이지는 않습니다.

**8. 보상과 정산**
배송 보상은 기본 배송료, 거리, 시간·신선도 보너스, 물류 특징으로 구성됩니다. 영업 종료까지 배송하지 못한 물류에는 페널티가 있습니다. 모든 물류를 조건에 맞게 배송하면 별 3개이고, 성공 비율이 높을수록 별이 늘어납니다.

**9. 화면 보는 법**
적재 물류 패널의 화살표는 배송지 방향입니다. 속도계 게이지의 강조색은 고속 모드입니다. 알림은 화면 위쪽에 잠깐 떴다가 사라집니다.

## New Rules / Values

## Acceptance Criteria

- [ ] 게임 설명을 누르면 로고와 출근·게임 설명·퇴근 버튼이 모두 사라지고 패널이 오른쪽 영역에 뜬다.
- [ ] 16:9와 21:9에서 패널이 차량을 가리지 않는다. 각 해상도 스크린샷을 `production/qa/evidence/`에 남긴다.
- [ ] 마우스 휠과 ↑/↓/PageUp/PageDown으로 끝까지 스크롤되고 본문이 잘리지 않는다.
- [ ] X를 누르면 패널이 사라지고 시작 메뉴와 로고가 다시 나온다. 다시 열면 맨 위부터 보인다.
- [ ] 패널이 열린 동안 하루가 시작되지 않고 카메라와 HUD 상태가 변하지 않는다.
- [ ] 키보드만으로 열기→스크롤→닫기가 되고, 닫으면 포커스가 게임 설명 버튼에 있다.
- [ ] 게임 설명 패널이 열려 있을 때 Esc는 패널만 닫고 확인창은 뜨지 않는다.
- [ ] 물류센터 창이 열려 있을 때 Esc는 창만 닫고 확인창은 뜨지 않는다.
- [ ] 하루 운영 중, 시작 메뉴, 정산 화면에서 Esc를 누르면 `게임을 정지하고 퇴근하시겠습니까?` 확인창이 뜬다.
- [ ] 확인창이 열려 있는 동안 게임 시계, 물류 시간(Express·Fresh), 차량이 멈추고 키 입력이 무시된다. 10초 뒤 `아니오`를 눌러도 영업 시각과 제한 시간이 그대로다.
- [ ] 확인창에서 Esc 또는 `아니오`는 재개, `예`는 종료(Editor 플레이 중지)다. 처음 포커스는 `아니오`이고 ←/→/Enter로 선택된다.
- [ ] Esc 한 번에 두 가지 동작이 겹치지 않는다(패널을 닫으면서 확인창이 뜨지 않음).
- [ ] 기존 기능 유지: 출근·퇴근 버튼, 카메라 블렌드, 키보드 포커스 강조, 물류센터 창의 X 닫기와 상호작용 닫기가 이전과 같다.
