# Quick Design Spec: 적재 물류 패널 접기/펼치기 + 스크롤

**Type**: Addition
**System**: HUD – 적재 물류 패널 (Story 006 `DurabilityHud`)
**GDD Reference**: `design/gdd/game-concept.md` 13장 / `design/game-brief.md` (GDD 없음 — Story 006 사용)
**Date**: 2026-11-17

## Change Summary

우측 상단 적재 물류 패널의 배송지 그룹을 숫자키로 개별 접고 펼 수 있게 하고, 패널 높이를 제한해 넘치면 스크롤한다. (2026-11-17: 패널이 물류센터·배송 현황·폐기로 나뉜 뒤 높이 제한·스크롤은 배송 현황 패널에만 적용, 숫자키는 배송 그룹 다음 폐기 그룹 순)

## Motivation

현재 패널은 모든 그룹을 항상 펼쳐 그리고 높이 제한이 없어, 물류가 많으면 화면 아래로 길어져 시야를 가린다. 필요한 배송지의 상세만 골라 보게 한다.

## Design Delta

- 현재: 모든 그룹이 항상 펼쳐져 있고 높이 제한·스크롤이 없다.
- 변경: 그룹은 기본 접힘. 숫자키로 개별 토글, `0` 전체 열기, `~` 전체 닫기. 패널 높이 상한을 두고 초과분은 스크롤.

## New Rules / Values

1. **그룹 번호**: 패널 위에서부터 1, 2, … 순번. 그룹 헤더에 `[1]` 번호 배지를 표시한다. 적재 변화로 순서가 바뀌면 번호도 따라 바뀐다. 번호는 9개 그룹까지 부여하고, 10번째부터는 배지 없이 표시되며 스크롤로만 접근한다(펼침 상태는 `0`으로 열 때만 바뀜).
2. **키 입력**(키보드 상단 숫자열만, 숫자패드 제외):
   - `1`~`9`: 해당 번호 그룹의 펼침/접힘 토글. 그 번호의 그룹이 없으면 무시.
   - `0`: 현재 존재하는 모든 그룹 열기(일회성).
   - `~`(Backquote): 모든 그룹 닫기(일회성).
3. **접힌 그룹**: 헤더 한 줄만 표시. `1 배송지명 ×N`(N=그룹 물류 수, 번호는 키캡 모양). 펼친 그룹은 기존처럼 물류 행(가격·태그·내구도)을 표시. 헤더 왼쪽에는 접힘 표시(`▶`/`▼`) 대신 방향 화살표를 둔다(2026-11-17, Story 017, `hud-layout-2026-11-17.md`).
4. **상태 유지**: 펼침 여부는 그룹 키(배송지 이름, 폐기 그룹은 "처분 장소")별로 기억한다. 적재·내구도 갱신으로 패널을 다시 그려도 유지하고, 그룹이 사라지면 상태도 버린다. 새로 생긴 그룹은 접힘. 일회성 `0`은 이후 생기는 그룹까지 열지 않는다.
5. **스크롤**: 목록 영역을 세로 `ScrollView`로 만들고 높이 상한 초과 시 스크롤바 없이 마우스 휠로 스크롤한다. 보조로 `PageUp`/`PageDown`(방향키는 주행 입력이라 제외). 접기로 내용이 줄어 스크롤 범위를 벗어나면 범위 안으로 되돌린다.
6. **조작 잠금**: 하루 종료(조작 잠금) 후에는 키 입력을 무시한다.
7. 적재 0개일 때 패널 숨김은 기존대로.

### Tuning Knobs

| Knob | Default | Range | Category | Rationale |

| 초기 펼침 상태 | 접힘 | 접힘/펼침 | feel | 화면을 덜 가리게 |

## Acceptance Criteria

- [ ] 기본 상태에서 모든 그룹이 접혀 헤더(번호·이름·개수)만 보인다
- [ ] `1`~`9`가 해당 번호 그룹만 토글하고, 없는 번호는 아무 일도 없다
- [ ] `0`은 전체 열기, `~`는 전체 닫기. 숫자패드 키는 반응하지 않는다
- [ ] 충돌로 내구도가 갱신돼도 펼침 상태가 유지된다
- [ ] 그룹이 많아 높이 상한을 넘으면 마우스 휠로 스크롤되고 패널이 상한을 넘지 않는다
- [ ] 하루 종료 후 키 입력이 무시된다
- [ ] No regression: 폐기 알림, 감소량 −N 팝업, 물류별 내구도 갱신(Story 006)
