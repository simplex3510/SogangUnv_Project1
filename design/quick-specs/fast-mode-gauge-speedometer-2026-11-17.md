# Quick Design Spec: 고속 모드 게이지와 속도계 HUD

**Type**: Addition
**System**: 주행 모드 (Vehicle Driving Mode) / 주행 HUD
**GDD Reference**: `design/gdd/game-concept.md` 10.4
**Date**: 2026-11-17
**Status**: 확정 (2026-11-17, `game-concept.md` 10.4에 참조 반영)

## Change Summary

고속(Fast) 모드에 사용 시간 제한 게이지를 둔다. 고속 중에는 게이지가 줄고, 다 떨어지면 일반(Normal) 모드로 강제 전환된다. 일반 모드를 유지하면 전환 직후 지연이 지난 뒤부터 게이지가 다시 찬다. 모드 전환에는 쿨다운이 있다. 화면 중앙 하단에 속도계(반원 아크 + 숫자 + km/h)와 그 아래 게이지 바를 둔다.

## Motivation

- 지금은 고속 모드에 비용이 없어 항상 켜 두는 것이 정답이 된다. 게이지는 "언제 고속을 쓸지"를 판단하게 만든다(배송 제한 시간 대응 구간에 아껴 쓰기).
- 쿨다운은 Ctrl 연타로 게이지 충전 지연을 피하는 것을 막는다.
- 속도계는 과적 감속(8.6)과 모드 차이를 플레이어가 숫자로 체감하게 한다.

## Design Delta

Current GDD says (`game-concept.md` 10.4):

> - 모드 전환에는 비용(연료·내구도 등)을 두지 않는다.

This spec changes that to:

> - 고속 모드는 사용 시간 게이지를 소모하고, 모드 전환에는 쿨다운이 있다(`design/quick-specs/fast-mode-gauge-speedometer-2026-11-17.md`). 연료·내구도 비용은 두지 않는다.

## Detailed Rules

게이지 `g`는 0~1 값이다. 하루 시작 시 `g` = 1.

1. **소모**: 고속 모드인 동안 `g`는 초당 `1 / T_drain`만큼 줄어든다(정지 중에도 줄어든다).
2. **강제 전환**: `g`가 0에 닿으면 즉시 일반 모드로 전환한다. 강제 전환은 쿨다운·접지·상호작용 조건을 무시한다. 이때 "소진" 상태가 된다.
3. **충전**: 일반 모드로 바뀐 순간부터 `T_delay`초가 지나면 `g`는 초당 `1 / T_recharge`만큼 찬다(최대 1).
4. **쿨다운**: 수동·강제를 가리지 않고 모드가 바뀐 뒤 `T_cooldown`초 동안 수동 전환 요청을 무시한다.
5. **고속 진입 조건**: 기존 조건(접지, 상호작용 중 아님) + 쿨다운 끝 + `g` > 0. "소진" 상태이면 `g` ≥ `g_reenter`여야 하며, 이 값에 닿으면 소진 상태가 풀린다.
6. 고속 → 일반 수동 전환은 쿨다운만 확인한다(게이지 조건 없음).
7. 하루 종료로 조작이 꺼진 동안 게이지·쿨다운 시간은 흐르지 않는다.

**속도계**
- 표시 속도 = |전진 속도(m/s)| × 3.6 × `k_display`, 정수로 반올림.
- 아크는 표시 속도 / `v_arcMax` 비율만큼 왼쪽 아래에서 시계 방향으로 찬다(반원보다 넓은 약 240° 아크, 레퍼런스 이미지 기준).
- 게이지 바는 `g` 비율로 찬다. 소진 상태에서는 경고색으로 표시한다.

## Formulas

- 고속 지속 시간(가득 찬 상태에서) = `T_drain`
- 0 → 1 충전 시간 = `T_delay` + `T_recharge`
- 소진 후 재진입까지 최소 시간 = `T_delay` + `g_reenter × T_recharge` = 1.5 + 0.3 × 12 = **5.1초**
- Fast 최고 속도 표시 = 5 m/s × 3.6 × 4 = **72 km/h**, Normal = 3 × 3.6 × 4 = **43 km/h**

## Tuning Knobs

`VehicleConfig`에 `TODO(tuning)`으로 둔다.

| 값 | 기호 | 초기값 |
|---|---|---|
| 고속 게이지 소모 시간 | `T_drain` | 8초 |
| 충전 시작 지연 | `T_delay` | 1.5초 |
| 0→1 충전 시간 | `T_recharge` | 12초 |
| 모드 전환 쿨다운 | `T_cooldown` | 1초 |
| 소진 후 재진입 게이지 | `g_reenter` | 0.3 |
| 속도 표시 배율 | `k_display` | 4 |
| 아크 최대 표시 속도 | `v_arcMax` | 80 km/h |

## Edge Cases

- 공중·상호작용 중 `g`가 0이 되어도 강제 전환은 일어난다(고속을 유지할 수 없다).
- 쿨다운 중 `g`가 0이 되어도 강제 전환은 일어나고, 쿨다운이 새로 시작된다.
- 후진 속도도 절댓값으로 표시한다.
- 과적 감속(8.6)은 실제 속도에 반영되므로 속도계에 그대로 나타난다.
