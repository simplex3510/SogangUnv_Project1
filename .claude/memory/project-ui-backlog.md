UI 관련 미개발 메모(겹침 문제, 동적 요소의 UXML 템플릿 분리 등)는 `production/ui-backlog.md`에 UI-NN 번호로 모은다(2026-11-17 시작).

**Why:** 사용자가 UI 메모를 당장 개발하지 않고, 나중에 `/quick-design` 등으로 UI 작업을 정할 때 한꺼번에 확인한 뒤 스토리로 만들겠다고 했다.

**How to apply:** UI 관련 문제나 아이디어를 "메모해 둬"라고 하면 이 파일에 항목을 추가한다. `/quick-design`, `/create-stories` 등에서 UI 작업을 다루면 먼저 이 목록 전체를 보여 주고 어느 항목을 넣을지 묻는다. 스토리가 된 항목은 닫힌 항목으로 옮긴다. 관련: [[project-ui-toolkit-migration]], [[feedback-ui-icons-svg]]
