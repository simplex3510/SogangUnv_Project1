2026-11-16 기준: 첫 릴리즈 배포 전 개발 단계. 제대로 된 GUI는 아직 없고 임시 UI만 있다. 추가 기획 사항이 마지막으로 한 번 더 업데이트될 예정이라 `production/epics/over-load/` 스토리 전반과 `design/game-brief.md`가 수정될 가능성이 높다.

**Why:** 사용자가 직접 "아직 미완성 개발단계임을 잊지마"라고 강조함.

**How to apply:** 스토리·브리프를 확정본으로 다루지 말 것. UI 관련 판단(스크린샷 증거 등)은 임시 UI 기준으로 보고, 최종 GUI 품질을 요구하지 말 것. 기획 업데이트가 오면 스토리 재작성이 정상 흐름이다. 별점 등 기획 규칙의 기준은 메모리가 아니라 브리프의 Goal & fail state.
