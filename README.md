# unity-ai-template

Claude Code로 Unity 게임을 만드는 프레임워크의 템플릿 저장소예요. CCGS(Claude Code Game Studios)에 Unity 플러그인·CLI, Ponytail, Graphify, Aseprite, git·gh를 묶었어요.

새 게임 만들기:

```powershell
pwsh scripts/new-game.ps1 <게임-slug>
```
