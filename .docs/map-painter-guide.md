# 맵 페인터 사용 가이드

> **대상:** 맵 레벨 디자인을 담당하는 아트 파트  
> **도구 위치:** Unity 상단 메뉴 `Tools > Over?Load! > 맵 페인터`  
> **작업 씬:** `Assets/Game/Scenes/Level01.unity`  

이 도구는 Unity 에디터에서 **2.25m 격자에 도로·건물·소품 조각을 클릭으로 배치**하는 도구입니다.  
Unity를 잘 몰라도 아래 순서만 따라 하면 맵을 그릴 수 있게 만들었습니다.

도움이 될진 모르겠으나, 유용하게 사용이 되었으면 좋겠습니다...ㅜㅜ

---

## 1. 5분 빠른 시작

1. Unity에서 이 프로젝트를 엽니다.
2. Project 창에서 `Assets > Game > Scenes > Level01`을 **더블 클릭**해 씬을 엽니다.
3. 상단 메뉴에서 **`Tools > Over?Load! > 맵 페인터`**를 클릭합니다.
4. 창 아래 **팔레트**에서 놓고 싶은 조각(예: 도로)을 클릭합니다.
5. **`맵에 그리기: 꺼짐`** 버튼을 눌러 **켜짐**으로 바꿉니다.
6. 가운데 3D 화면(씬 뷰)에서 원하는 칸을 클릭합니다. 조각이 배치됩니다.
7. 다 그렸으면 **`Esc`**를 눌러 그리기를 끄고, **`Ctrl+S`**로 저장합니다.

> 잘못 놓았을 때는 **`Ctrl+Z`**를 누르면 바로 되돌아갑니다.

### 상태 표시줄
창 가운데의 **고른 조각 / 모드 / 회전 / 그리기** 줄입니다.  
"지금 무엇을 놓을지, 그리기가 켜져 있는지"를 항상 확인하세요.

## 3. 기본 사용법

### 3.1 조각 고르기
팔레트에서 조각을 클릭합니다.  
선택된 조각은 초록색으로 표시됩니다.  
마우스를 올리면 **조각 이름과 실제 크기**(예: `3.0m × 3.0m`)가 툴팁으로 나옵니다.

### 3.2 배치하기
1. `맵에 그리기`를 **켜짐**으로 바꿉니다.
2. 씬 뷰에서 원하는 칸으로 마우스를 옮기면, **초록색 상자**로 놓일 위치와 크기가 미리 보입니다.
3. 왼쪽 버튼을 클릭하면 배치됩니다. **누른 채로 드래그**하면 지나가는 칸에 연속으로 배치됩니다.

> 초록색 상자 위의 글씨는 "지금 놓을 조각 이름과 크기"입니다.

### 3.3 회전하기
조각을 놓기 전에 **`회전`** 버튼을 누르거나 씬 뷰에서 **`R`** 키를 누르면 90°씩 돌아갑니다.  
(예: 0° → 90° → 180° → 270° → 0°)

### 3.4 지우기
1. **`지우기`** 버튼을 누릅니다.
2. 지울 조각 위를 클릭하면 삭제됩니다. 마우스를 올리면 "지울 조각: 이름"이 표시됩니다.

### 3.5 되돌리기
**`Ctrl+Z`** — 방금 한 배치·삭제가 취소됩니다.  
**`Ctrl+Y`** — 되돌린 작업을 다시 실행합니다.
드래그로 한 번에 놓은 조각들은 한 번에 되돌아갑니다.

### 3.6 그리기 끄기
**`Esc`** 또는 `맵에 그리기` 버튼을 다시 누릅니다.  
그리기가 켜져 있는 동안에는 클릭이 **배치**로 동작해서, 다른 오브젝트를 선택할 수 없습니다.  
오브젝트를 선택하려면 먼저 `Esc`로 그리기를 끄세요.

## 4. 씬 뷰 카메라 조작 (Unity 기본)

| 조작 | 방법 |
|---|---|
| 시점 회전 | `Alt` + 왼쪽 드래그 |
| 화면 이동 | 마우스 가운데 버튼 드래그 |
| 확대/축소 | 마우스 휠 |
| 위에서 내려다보기 | 창의 **`탑뷰로 보기`** 버튼 |

> 배치는 **탑뷰**에서 하는 것이 가장 편합니다. `Alt`를 누른 채 클릭하면 맵 페인터가 반응하지 않고 카메라만 움직입니다.

## 5. 설정 항목

| 항목 | 설명 | 기본값 |
|---|---|---|
| 칸 크기(m) | 격자 한 칸의 크기. 현재 도로 폭과 같습니다. | `2.25` |
| 놓는 높이(Y) | 조각을 놓을 높이. 보통 `0`으로 둡니다. | `0` |
| 묶을 오브젝트 이름 | 배치한 조각을 모아 둘 오브젝트. 없으면 자동 생성됩니다. | `Map` |
| 이미 놓인 칸은 건너뛰기 | 켜면 같은 칸에 겹쳐 놓지 않습니다. | 켜짐 |
| 팔레트 폴더 | 프리팹을 읽어 올 폴더입니다. | `Assets/Game/Prefabs/Map` |

## 6. 팔레트 관리

팔레트는 **지정한 폴더를 자동으로 읽어** 채워집니다. 폴더의 **하위 폴더 이름이 분류**가 됩니다.

```
Assets/Game/Prefabs/Map/
├─ Roads/          → 팔레트의 [도로]
├─ Buildings/      → 팔레트의 [건물]
├─ Props/          → 팔레트의 [소품]
└─ Environment/    → 팔레트의 [환경]
```

- 새 프리팹을 폴더에 넣은 뒤 창의 **`새로고침`** 버튼을 누르면 목록에 나타납니다.
- 알려진 폴더 이름(`Roads`, `Buildings`, `Props`, `Environment`)은 한글로 표시되고,
  그 외 이름은 폴더 이름 그대로 표시됩니다.
- 분류 제목을 클릭하면 접었다 펼 수 있습니다.
- 분류 순서는 **도로 → 건물 → 소품 → 환경**입니다.

## 7. 작업 규칙

1. **칸 크기는 2.25m를 유지**합니다. 도로 폭과 맞춰져 있어, 바꾸면 도로가 어긋납니다.
2. 조각은 **`Map` 오브젝트 아래**에만 둡니다. (도구가 자동으로 넣습니다.)
3. 프리팹 파일 자체를 고치지 말고, **배치로** 해결합니다.
4. 작업 후 **`Ctrl+S`**로 씬을 저장합니다.
5. 씬·프리팹 파일의 **이름을 바꾸거나 옮기지 않습니다.** (다른 시스템이 경로로 참조합니다.)

## 8. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 팔레트가 비어 있음 | 폴더에 프리팹이 없거나 경로가 틀림 | 경로 확인 후 `새로고침` |
| "폴더를 찾을 수 없습니다" 경고 | 폴더가 아직 없음 | 프리팹 폴더를 만들고 경로를 입력 |
| 클릭해도 아무것도 안 놓임 | 그리기 꺼짐 / 조각 미선택 / 플레이 중 | `맵에 그리기` 켜기, 조각 선택, Play 종료 |
| 다른 오브젝트 선택이 안 됨 | 그리기가 켜져 있음 | `Esc` |
| "플레이 중에는 사용할 수 없습니다" | Play 모드 실행 중 | 상단의 ▶ 버튼을 눌러 Play 종료 |
| 미리보기 상자가 안 보임 | 카메라 각도가 너무 낮음 / 조각 미선택 | `탑뷰로 보기`, 조각 선택 |
| 잘못 놓았음 | — | `Ctrl+Z` 또는 `지우기` 모드로 클릭 |
| 격자가 안 맞음 | 칸 크기 변경됨 | `칸 크기(m)`를 `2.25`로 되돌리기 |
| 글자가 네모(□)로 보임 | OS 폰트 문제 | 담당자에게 알리기 |
